# Assignment #2 — Advanced CSS (Flexbox & Grid)

A small multi-page site demonstrating Flexbox and CSS Grid layout techniques.

## Pages

 File | Task | Concept 
 `index.html` | Task 0 | Flexbox navbar (logo left, links right, vertically centered) |
 `task1.html` | Task 1 | Flexbox card row (equal-height cards, gaps, hover effect) |
 `task2.html` | Task 2 | CSS Grid page layout using `grid-template-areas` (header/sidebar/main/footer) |
 `task3.html` | Task 3 | CSS Grid image gallery (3 columns, 9 images, hover caption overlay) |
 `task4.html` | Task 4 | Flexbox + Grid combined portfolio page |

All pages share `style.css` and the same navbar, so you can click between tasks from any page.

## How to run locally

Just open `index.html` in a browser — no build step or server required.

## Deployment

Deployed with **GitHub Pages**:

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Set the source to the `main` branch, root folder.
4. The site will be available at `https://<your-username>.github.io/<repo-name>/`.

(Alternatively, drag-and-drop this folder into [Netlify Drop](https://app.netlify.com/drop) for instant hosting.)
